# MMIS Lab website

Website of the **Multimodal Medical Imaging Systems (MMIS) Lab**, Department of Bioscience and Bioengineering, IIT Jodhpur.

Built with Jekyll and hosted free on GitHub Pages. Everything you will normally change is plain text — no coding needed.

**➜ See [EDITING-GUIDE.md](EDITING-GUIDE.md) for how to launch the site and how to add news, team members, pictures and publications.**

| What | Where |
|---|---|
| Lab name, email, address, social links | `_config.yml` |
| Research areas | `_research/` (one file per area) |
| Team members | `_data/team.yml` |
| Publications | `_data/publications.yml` |
| News posts | `_posts/` (one file per post) |
| Join Us / Contact text | `join.md`, `contact.md` |
| Home page text | `index.html` |
| Pictures | `assets/images/` (`team/`, `news/`, `research/`) |
| Colours and fonts | top of `assets/css/style.css` |
